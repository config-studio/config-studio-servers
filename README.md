Официальный плагин **Servers & Fleet Manager** для [Config Studio](https://github.com/config-studio/config-studio). 
Является единым центром управления инфраструктурой, объединяющим инвентарь `servers.yaml v2`, прямое SSH/SFTP управление, встроенную умную доставку агентов (**Smart Plugin-Embedded Agent Distribution**), сканирование локальной сети (LAN Discovery) и безопасную передачу файлов.

---

## Ключевые возможности

### 1. Универсальный переключатель в шапке (Universal Fleet Switcher)
- Единая компактная кнопка со статусом активного узла, выпадающий список выбора хостов и индикация задержки (`ping ms`).
- **Гибридные действия для каждого сервера:**
  - `Агент`: прямое чтение и запись файлов через быстрый REST API агента с двухсоставной TOTP-авторизацией.
  - `SFTP`: переход к удаленной файловой системе сервера через нативный SFTP ядра в сайдбаре.
  - `Шелл`: мгновенный запуск интерактивной сессии SSH PTY терминала в нижней панели (Bottom Dock).

### 2. Smart Plugin-Embedded Agent Distribution (Air-Gapped & NAT Ready)
- Скомпилированные бинарники демона `config-studio-agent` (`linux-amd64` и `linux-arm64`) упакованы прямо внутрь пакета `servers.cspkg`.
- **Работа в закрытых контурах:** целевым серверам не нужен доступ к Интернету; установка и обновление происходят через прямой стриминг `ZIP -> SFTP` из пакета на машине оператора.
- **Атомарная ротация `PosixRename`:**
  - Временный файл `.tmp` создается строго в целевой директории, исключая ошибку `EXDEV: cross-device link`.
  - Запущенный бинарник переносится в `.bak` (процесс продолжает безопасно работать в памяти со своим Inode), а на его место встает новый исполняемый файл.
  - При сбое проверки `/api/health` срабатывает автоматический откат на предыдущую версию.

### 3. Инвентарь серверов `servers.yaml v2`
- Все серверы описываются в стандартизированном файле `servers.yaml` v2: хост, порт, пользователь, признак Canary, теги (`prod`, `staging`, `web`) и pre/post hooks.
- Каноническое поле `vault_secret` с автоматической валидацией схемы и динамической подгрузкой хостов ядра.
- Встроенный редактор YAML с подсветкой синтаксиса и сохранением в 1 клик.
- Быстрая фильтрация по тегам и группам в боковой панели.

### 4. Zero-Secret Безопасность через Core Vault (`agent_credentials`)
- Никакие пароли, секретные ключи SSH или токены TOTP не хранятся в открытом виде в `servers.yaml`.
- Для реквизитов подключения агентов выделена системная категория `agent_credentials` с двухсоставным TOTP-ключом.
- В выпадающих списках ключей отображаются понятные имена `Title [ID]` с фирменным бирюзовым бейджем `AGENT`.

### 5. 1-Click Автоустановка агента (Daemon Auto-Onboarding via SSH)
- Автоматическое определение архитектуры (`linux/amd64`, `linux/arm64`) и системы инициализации (`systemd` / `OpenRC` / `nohup`) удаленного сервера через SSH.
- Выбор кастомного порта агента (по умолчанию `8085`).
- Автоматическая потоковая загрузка бинарника по SFTP с ускорением `UseConcurrentWrites`.
- **Нативная системная активация через `config-studio-agent -install`**:
  - Атомарная ротация бинарника с резервной копией `.bak` (защита от сбоев).
  - Вызов `config-studio-agent -install -port <port> -roots <paths> -raw` прямо на целевом хосте, что гарантирует единый и проверенный способ развертывания службы и генерации `agent.yaml`.
  - В режиме обновления (`UpgradeOnly`) автоматически сохраняются существующие секреты и настройки.
- Защита SSH-сессий: использование регулярного выражения `pkill -f '[c]onfig-studio-agent'` (обход ограничения Linux `TASK_COMM_LEN` в 15 символов) и перенаправление дескрипторов `</dev/null >/dev/null 2>&1 &`.

### 6. Ручная установка и 1-Click импорт по ссылке (Manual Setup & Connection Link)
- **Установка демона без SSH-доступа от имени root:**
  ```bash
  # Установка как системная служба с генерацией ключей и ссылок:
  sudo ./config-studio-agent -install -port 8085 -roots "/opt/projects,/var/www" -name "Production VPS"

  # Вывод чистой ссылки подключения:
  sudo ./config-studio-agent -install -port 8085 -roots "/opt/projects,/var/www" -raw
  # Выведет: cs-agent://cs_key_...:...@ip:8085/?roots=...#Production%20VPS
  ```
- **1-Click импорт в Config Studio:**
  - В модальном окне «Агент вручную» достаточно вставить скопированную ссылку `cs-agent://...` в поле быстрого импорта: IP, порт, постоянный API-ключ `cs_key_<32hex>`, TOTP-секрет и рабочие папки заполнятся моментально.
  - Реквизиты сохраняются в зашифрованный Vault ядра (`agent:<server_id>`), а в `servers.yaml` записывается аккуратная ссылка `vault_secret`.

### 7. Пакетный импорт узлов по ссылкам (Batch Link Import)
- Если агенты развернуты сразу на группу серверов через скрипты автоматизации (Ansible, Bash, Terraform, Cloud-Init):
  - Откройте окно **«Импорт ссылок»** (доступно из сайдбара, шапки флота или модального окна установки).
  - Вставьте список полученных ссылок `cs-agent://...` прямо из терминала или логов развертывания (поддерживаются комментарии `#`, строки логов и фрагменты текста).
  - **Интерактивная таблица предпросмотра:**
    - Автоматическое распознавание сетевого адреса, порта, API-ключа, TOTP-секрета и списка рабочих папок.
    - Автоматическое разрешение коллизий ID (правило обновления существующих либо генерация уникальных ID `-2`, `-3`).
    - Кнопка **«⚡ Проверить связь»** для одновременного параллельного тестирования доступности и TOTP-прав всех узлов до их сохранения.
    - Массовая запись секретов в Core Vault и регистрация серверов в `servers.yaml` с индикацией прогресса.

### 8. Автообнаружение в локальной сети (LAN Discovery) & 1-Click Adopt
- Быстрое параллельное сканирование локальной подсети (`192.168.x.1..254`) на наличие запущенных демонов `config-studio-agent`.
- Сопряжение обнаруженного узла во флот нажатием кнопки «Принять (Adopt)» в 1 клик.

### 8. Передача файлов на узел (Deploy to Fleet)
- Отправка открытого в редакторе файла на любой сервер флота или группу узлов с подтверждением пути назначения.

### 9. Дизайн-система `@config-studio/ui`
- Все окна приведены к эталонным размерам дизайн-системы: `.cs-fleet-modal-lg cs-fleet-modal-fixed` (720px, фиксированная высота) и `.cs-fleet-modal-md` (540px).
- Кастомные Dropdown-селекторы с индикаторами статуса серверов, бейджами типов секретов и автоматическим разворотом вверх (`openUpward`) при нехватке места.

## Установка

### В 1 клик из приложения (рекомендуется)
1. В Config Studio откройте **Настройки → Плагины → вкладка Каталог**.
2. Найдите **Флот серверов & Инвентарь (`servers`)** и нажмите **«Установить»** (или «Обновить»).

### Установка пакета `.cspkg`
1. Скачайте актуальный бинарный пакет `servers.cspkg` со страницы [Релизов](https://github.com/config-studio/config-studio-servers/releases).
2. Перетащите скачанный файл `.cspkg` в окно настроек Config Studio (вкладка «Плагины»).
