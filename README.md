# Config Studio Servers & Fleet Manager Plugin (`servers`)

Официальный плагин Config Studio для управления флотом серверов и инвентарем `servers.yaml`.

## Возможности
- **Универсальный переключатель в шапке (Universal Fleet Switcher)**: единая кнопка и выпадающая панель инстансов вместо разрозненных плагинов.
- **Интеграция протоколов**:
  - `⚡ Агент`: прямое сохранение и чтение через быстрый HTTP REST API с TOTP.
  - `📁 SFTP`: навигация по файловой системе через SFTP ядра.
  - `>_ Шелл`: интерактивный SSH PTY терминал в нижнем доке.
- **Схема `servers.yaml`**: хранение топологии серверов, групп, тегов, порядка развертывания (canary, rollout hooks).
- **Zero-Secret безопасность**: учетные данные (пароли, SSH ключи, TOTP токены) хранятся исключительно в зашифрованном хранилище Core Vault (`window.ConfigStudio.secrets`).
- **Сайдбар инвентаря**: быстрый фильтр по тегам и группам, статус доступности и задержки (ping ms).

## Установка
Плагин распространяется как пакет `.cspkg` для Config Studio v2.0+.
